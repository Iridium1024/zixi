# 字隙 Zixi v0.2.1 / Zixi v0.2.1

## 本次更新 / What’s improved

- **窗口与面板**：主窗口和独立阅读窗口使用自定义标题栏与边缘缩放；主导航、便签列表和便签设置面板可分别收起。 / The main and reader windows have custom title bars and resize handles; navigation and note panels can be collapsed independently.
- **便签编辑保护**：切换页面、便签或新建便签前先保存当前草稿；保存失败或存在冲突时保留草稿并阻止切换。搜索无匹配结果时提供明确提示。 / The app flushes the current note before navigation or creation and keeps the draft in place if saving fails or a conflict needs attention. Empty search results are clearly identified.
- **书架排序与同步**：支持按最近使用、导入时间、书名或阅读进度排序，并同步独立阅读窗口的打开时间与进度。 / Sort the library by recent use, import time, title, or reading progress, with updates from independent reader windows.
- **项目整理**：更新项目简介、使用指南和依赖版本说明，并移除不再使用的界面样式。 / Updated project and dependency documentation and removed unused interface styles.
