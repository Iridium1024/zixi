# 字隙 Zixi v0.1.1 / Zixi v0.1.1

## 用户可见改善 / What’s improved

- **直接启动 / Direct launch** — 新增完整免安装包：解压后双击根目录 `zixi.exe` 即可使用；字体与说明随包提供。 / The new portable package runs from the root `zixi.exe` after extraction, with fonts and guidance included.
- **更清晰的下载选择 / Clearer downloads** — Release 明确区分安装版、免安装版、MSI 和源码，便于选择。 / The Release clearly distinguishes installer, portable, MSI, and source downloads.
- **更容易理解的资料结构 / Easier documentation** — 根目录 README 只保留入口与分类，详细使用与开发资料集中在 `docs/`，也便于外部工具或 Agent 定位内容。 / The root README now provides only entry points and a map; detailed material lives in `docs/`, which also helps external tools and agents locate it.
- **按需创建快捷方式 / Opt-in shortcuts** — 默认不写入桌面；需要时可自行创建快捷方式。 / No desktop shortcut is created by default; create one only when wanted.

## 关键改动 / Key details

- 发布文件按版本归档，并提供 `SHA256SUMS.txt`；发布流程会检查源码上传范围、版本一致性和免安装包内容。 / Release files are versioned and include `SHA256SUMS.txt`; the release flow checks source scope, version consistency, and portable-package contents.
- 独立文字比较窗口仍是同一个 `zixi.exe` 内的功能，不会产生额外启动入口。 / The independent text-comparison window remains a feature of the same `zixi.exe`, not another launcher.
- 本版本不迁移或删除数据；用户数据仍位于 `%APPDATA%\com.zixi.desktop`。 / This version neither migrates nor deletes data; user data remains in `%APPDATA%\com.zixi.desktop`.

## 下载与提示 / Downloads and notes

- `Zixi-0.1.1-Windows-x64-Setup.exe`：适合多数用户的安装版 / installer for most users.
- `Zixi-0.1.1-Windows-x64-Portable.zip`：完整解压后直接运行 / fully extract, then run directly.
- `Zixi-0.1.1-Windows-x64.msi`：供需要 MSI 的部署环境使用 / for MSI-based deployment environments.
- GitHub 自动生成的 Source code ZIP/TAR.GZ 仅为源码，不含已编译 EXE。 / GitHub-generated Source code ZIP/TAR.GZ contains source only, not a compiled EXE.

Windows 10/11 x64 is supported. The portable package needs Microsoft Edge WebView2 Runtime; use the installer if it is missing. This build is not commercially code-signed; download only from the official Release and verify `SHA256SUMS.txt`.
