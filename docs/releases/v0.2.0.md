# 字隙 Zixi v0.2.0 / Zixi v0.2.0

## 用户可见改善 / What’s improved

- **本地 TXT 书架与独立阅读窗 / Local TXT library and reader windows** — 导入 TXT 后由应用保存受管副本，并在独立、可调整大小的阅读窗口中继续阅读；书架同步显示阅读进度。 / Imported TXT files are kept as app-managed copies and opened in independent resizable reader windows, with progress synchronized back to the library.
- **局部渲染阅读 / Bounded rendering** — 长文本按章节和内部区块局部渲染，支持滚动与分页模式、章节目录、方向键翻页/换章，以及滚动到边界后继续切换章节。 / Long texts use chapter/block-bounded rendering with scrolling and paged modes, a table of contents, keyboard navigation, and intentional wheel navigation across chapter boundaries.
- **更灵活的阅读外观 / Reader appearance controls** — 可调整字号、行距、字体、正文宽度、首行缩进、背景透明度、文字颜色和阴影；背景透明不会降低文字不透明度。 / Font size, line height, family, content width, indentation, background opacity, text color, and shadow can be customized without making text translucent.
- **可靠恢复隐藏窗口 / Reliable hidden-window recovery** — 阅读窗内按 `B` 可临时隐藏，并可通过可配置的全局组合键或托盘菜单恢复最近活动的阅读窗。 / Press `B` inside a reader to hide it temporarily, then recover the most recently active reader via a configurable global shortcut or the tray menu.
- **便签关闭策略与快捷保存 / Note close policies and quick save** — 独立便签支持退出时询问、自动保存或不保存，并补充通用 `Ctrl+S` 保存；新建空白便签也会被视为需要确认的变更。 / Independent notes can ask, save, or discard on close and support `Ctrl+S`; even a newly created blank note is treated as a change requiring a decision.
- **独立窗口行为 / Independent-window behavior** — 可分别设置打开或关闭独立便签、比较窗口和阅读窗口时，主窗口保持、最小化、隐藏或重新显示。 / Main-window behavior can be configured independently when note, comparison, and reader windows open or close.

## 关键改动 / Key details

- TXT 导入支持常见中文与日文编码探测及手动修正；阅读位置使用稳定文本锚点保存，而不是依赖易变化的页码。 / TXT import detects common Chinese and Japanese encodings with manual correction; reading positions use stable text anchors instead of fragile page numbers.
- 独立阅读窗口使用专属 Tauri capability；关闭前进度保存失败时会中止关闭，避免静默丢失阅读位置。 / Reader windows use a dedicated Tauri capability, and a failed progress save aborts closing instead of silently losing the reading position.
- 清理了桌面版本未引用的移动端与商店图标输出，并保留 Windows/macOS 构建及 ICO 生成实际需要的图标。 / Unused mobile and store icon outputs were removed while retaining assets required by Windows/macOS builds and ICO generation.
- 本次升级会在现有 SQLite 数据库中新增阅读器数据表，不会删除既有比较记录或便签。用户数据仍位于 `%APPDATA%\com.zixi.desktop`。 / This upgrade adds reader tables to the existing SQLite database and does not delete existing comparisons or notes. User data remains in `%APPDATA%\com.zixi.desktop`.
