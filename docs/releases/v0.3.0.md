# 字隙 Zixi v0.3.0

## 更新内容

- 新增初版思维导图：结构编辑、折叠、独立窗口与协作 JSON 文件导入；保留并发编辑保护。
- 统一展开导航与收起图标栏，轻量化工具按钮、提示、确认弹窗和表单控件；调整主题切换、列表状态及内容边缘渐隐。
- 便签支持单层文件夹、排序、拖放归类和 Ctrl 多选；删除文件夹保留便签，移回未分类。
- 设置新增“更改存储位置”：重启后迁移并校验数据库、书库、协作文件及外观资源，更新内部路径；失败继续使用原目录，旧资料保留为备份。
- 文字对比改进比较规则与异步计算保护、稿件复制和导出入口；行号区域缩小四分之一，补充正文页边距，并在离开视图前等待保存。
- 更新便签关闭保存选项、快捷索引、阅读器目录与排序，以及相关局部回归测试。

## 下载

- `Zixi-0.3.0-Windows-x64-Portable.zip`：免安装版，完整解压后运行 `zixi.exe`，保留 `fonts` 文件夹。
- `Zixi-0.3.0-Windows-x64-Setup.exe`：常规安装版。
- `Zixi-0.3.0-Windows-x64.msi`：MSI 安装版。
- `SHA256SUMS.txt`：以上三个程序包的 SHA-256 校验值。

面向 Windows 10/11 x64。免安装版需要系统 WebView2 Runtime。程序未进行商业代码签名。

默认资料位于应用的 AppData 目录；可在“设置 → 数据与备份”选择新存放位置，在其中创建 `ZixiData`。升级和迁移前请保存并关闭独立窗口。少量启动配置、窗口布局与 WebView 用户数据仍在系统目录；保留默认目录中的 `storage-location.json`，以便启动时定位迁移后的资料。用户自行迁移前，升级不会自动移动现有资料。
